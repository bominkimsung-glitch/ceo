## 목표

고객사 해외출원 사건(약 2년치)의 file wrapper를 DB로 정리한다.
- **이력(file wrapper 목록)은 전 사건 엑셀 1개로**
- **파일은 주요 서류만** 받아서 날짜순으로 이름을 바꿔 보관 (출원인 DB 업로드용)

## 지금까지 결정된 것

1. 자료 출처: KIPRIS 해외특허 → **심사정보조회(심사목록 상세화면)**. 여기서 file wrapper 목록 확인과 원문 다운로드가 된다.
2. 전 서류 zip 일괄 다운로드는 **쓰지 않기로 함**. 다운로드가 오래 걸리고, 대부분 행정 서류(접수증, 수수료, 검색기록 등)라 DB에 필요 없으며,
   중국 건 일부는 다운로드가 안 됨.
3. 대신 **사건 폴더 방식**으로 진행:
   - 사건 폴더 = `관리번호_국가_출원번호` (예: `ABCD240001EPA_EP_22123456`)
   - 안에 KIPRIS 심사목록 **캡처(이력1.png …) 또는 이력.txt** + 직접 받은 **주요 서류**
   - 사무실 PC에서 Claude Code를 실행해 "file wrapper 정리해줘" → 캡처를 이력.txt로 옮기고 `npm run cases` 실행
     (절차: 저장소 루트 `.claude/skills/file-wrapper/SKILL.md`)

## 만들어 둔 것 (`tools/kipris-filewrapper`)

| 명령 | 용도 | 상태 |
|---|---|---|
| `npm run cases -- "<사건루트>"` | **주력.** 사건 폴더별 이력.txt + 주요 서류 → `정리/`에 `제출일_국가번호_서류명.pdf`로 복사, 사건루트에 `file_wrapper_이력.xlsx` (사건목록 / 이력 시트) | 가짜 사건 폴더로 테스트 완료. 실제 개별 다운로드 파일로는 미검증 |
| `npm run organize` | 전 서류 zip 일괄 정리 (PDF 텍스트/OCR로 출원번호 자동 식별) | CN/KR/JP/EP/US 샘플 zip 5개로 검증 완료. 현재는 보조 도구 |

- 이력.txt 형식: KIPRIS 표를 드래그 복사한 탭 구분 텍스트, 또는 `서류명 YYYY.MM.DD 문서그룹` 한 줄씩. 상단에 `출원번호/출원일자/발명의 명칭/출원인` 줄.
- 파일 ↔ 이력 연결: 파일명 `YYYYMMDD_서류명.pdf`의 날짜·서류명으로 매칭 (특수문자 무시). 안 맞으면 "이력에 없는 파일 - 확인 필요".
- 구분 자동 분류: 출원 서류가 처음 나온 날 = 출원, 그 전 = PCT/출원 전, 등록 키워드(allowance, grant, 등록결정 등) = 등록, 나머지 = 중간.

## 다음에 할 일

1. **[필수] 개별 다운로드 파일명 확인**
   KIPRIS 심사목록에서 "원문" 버튼으로 하나씩 받은 파일의 파일명 형식을 아직 모른다.
   사용자에게 샘플 1~2개를 받아, `YYYYMMDD_서류명.pdf` 형식이 아니면 `src/cases.js`의 `matchRow`를 그 형식에 맞게 고친다.
2. **[필수] 사무실 PC 세팅**
   - Claude Code 설치, 이 저장소 clone (브랜치 `claude/compassionate-mccarthy-9anjtd`), `tools/kipris-filewrapper`에서 `npm install`
   - 사건 루트 폴더 위치 결정 (저장소 밖 권장) → `config.json`에 `"casesRoot"` 지정
3. **주요 서류 기준 확정** (사용자와 합의 필요)
   출원인 DB에 올릴 서류 종류를 국가별로 정한다. 초안:
   출원(진입서·출원 시 청구항·Filing Receipt/출원번호 통지), 중간(OA·의견서·보정서·거절결정·심판청구·권리이전),
   등록(허여/등록결정·등록증). 고객사 요구 목록이 있으면 그걸 따른다.
4. **실제 사건 몇 건으로 시범 운영** → 캡처 판독 정확도, 매칭 실패 사례 확인 후 보완
5. (선택) 사내 사건 목록 엑셀(관리번호↔출원번호)이 있으면 받아서 관리번호 자동 매칭 추가
6. (선택) KIPRIS에서 다운로드 안 되는 중국 건: 최근 출원(공개 전)인지 확인. 안 되면 현지 대리인에게
   사건 진행현황표 + 주요 통지서 PDF 일괄 요청하는 방안
7. (선택, organize 쪽) US/EP OCR 화면에 보이는 현지대리인 관리번호(Atty Docket No, Reference)도 추출
