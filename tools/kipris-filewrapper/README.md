# KIPRIS 해외 file wrapper 정리 도구

KIPRIS 해외특허 → **심사정보조회**에서 받은 zip 파일들을 한 폴더에 모아두고 실행하면:

1. 각 zip 안의 PDF 텍스트에서 **출원번호를 자동으로 찾아** 사건별 폴더로 풉니다
   (zip 파일명에는 출원번호가 없기 때문)
2. 파일명을 `2024-04-10_서류명.pdf` 형식으로 정리합니다
3. **사건목록 / 서류목록 엑셀**(`output/filewrapper_db.xlsx`)을 만듭니다

## 처음 설치 (최초 1회)

```bash
cd tools/kipris-filewrapper
npm install
```

## 사용 방법

1. KIPRIS에서 사건마다 심사정보조회 → 전체 선택 → 다운로드
2. 받은 zip을 전부 `tools/kipris-filewrapper/input/` 폴더에 넣기 (파일명은 그대로 둬도 됨.
   국가별·고객사별 하위 폴더로 나눠 넣어도 모두 읽음)
3. 실행

```bash
npm run organize
```

결과:

```
output/
  filewrapper_db.xlsx          # 사건목록 / 서류목록 시트 (필터, 파일 링크 포함)
  cases/
    CN_202380012345.6/
      2024-03-15_Request for substantive examination.pdf
      2024-04-10_Notice of international application for entering the national phase of China.pdf
      ...
    _미식별/                    # 출원번호를 못 찾은 zip (아래 참고)
```

- 실행할 때마다 `input/`의 zip 전체로 `output/`을 **새로 만듭니다**. 엑셀을 직접 고칠 거면 다른 곳에 복사해서 쓰세요.
- 같은 사건을 나중에 다시 받아 넣어도 한 폴더로 합쳐지고, 같은 서류는 한 번만 들어갑니다.
  그래서 새 서류가 나오면 그 사건 zip만 새로 받아 `input/`에 추가하고 다시 실행하면 됩니다.

## 자동으로 찾는 정보

| 항목 | 찾는 방법 |
|---|---|
| 출원번호 | PDF 텍스트에서 CN(`申请号 202380012345.6`), US(`17/123,456`), EP(`Application No. 23123456.7`), JP(`特願2023-123456`, 전각 숫자 포함), KR(`10-2023-0123456`) 형식을 찾아 가장 많이 나온 번호 채택. KR 번호는 해외 서류에 우선권 번호로도 나오므로 다른 국가 번호가 없을 때만 사용 |
| PCT번호 | `PCT/KR2023/000001` 형식 |
| 관리번호(추정) | 한국 서식의 `【참조번호】`, 없으면 명세서 머리글 등에 찍힌 사무소 관리번호 (기본 형식: `ABCD240001KRA`처럼 영문+숫자+영문). 일본 건처럼 서류에 사무소 번호가 없으면 비어 있으니 mapping.csv로 채움 |
| 현지대리인번호 | 일본 서식의 `【整理番号】` / `[Reference Number]` |
| 언어 | 텍스트로 추정 (KO/JA/ZH/EN). 일본 건은 KIPRIS가 원문(JA)과 영문 번역본(EN)을 같이 주므로 파일명 끝에 `_JA`, `_EN`을 붙여 구분. 스캔 이미지라 텍스트가 없으면 빈칸 |
| 서류구분 | 명세서·청구항·국내진입서 등 출원 서류가 처음 나온 날짜의 서류는 **출원**, 서류명에 등록 관련 단어(grant, allowance, certificate, annual fee, 등록결정 등)가 있으면 **등록**, 나머지는 **중간** |

서류구분은 규칙에 따른 자동 추정이므로 엑셀에서 필터로 한 번 훑어보는 것을 권장합니다.

## 스캔 PDF (미국·유럽 등) - OCR

미국·유럽 file wrapper는 PDF가 전부 스캔 이미지라 텍스트가 없습니다. 이런 zip은 자동으로
Filing Receipt, 관청 통지서(Communication, Notification 등) 같은 서류 최대 5개의 첫 페이지를
OCR 해서 출원번호를 찾습니다 (zip 1개당 10초 안팎, 별도 프로그램 설치 불필요).

- OCR 결과는 `output/ocr-cache.json`에 저장되어 다음 실행 때는 다시 OCR 하지 않습니다.
- OCR로 찾은 사건은 엑셀 "사건목록"의 상태 열에 `OCR로 인식 - 번호 확인 권장`이 표시됩니다.

## 출원번호를 못 찾은 경우 (`_미식별`)

OCR로도 번호를 못 찾으면 `_미식별` 폴더로 갑니다.
이때는 `input/mapping.csv`를 만들어 직접 적어주고 다시 실행하세요
(엑셀에서 "CSV UTF-8"로 저장해도 됩니다). `mapping.example.csv` 참고.

```csv
zip파일명,국가,출원번호,관리번호
20260924110000000.zip,US,"17/123,456",ABCD240001USA
```

mapping.csv에 적은 값은 자동 인식 결과보다 우선합니다 (잘못 인식된 경우 수정용으로도 사용).

## 사건 폴더 정리 (이력 엑셀 + 주요 서류만)

전체 zip 대신, **KIPRIS 심사목록(이력)** 과 **직접 고른 주요 서류**만 사건별 폴더에 넣고 정리하는 방식입니다.

### 폴더 만들기

```
D:\해외사건\                           <- 사건루트 (어디든 가능, 저장소 밖 권장)
  ABCD240001EPA_EP_22123456\          <- 관리번호_국가_출원번호 (관리번호 생략 가능, 출원번호는 숫자만)
    이력.txt
    20240321_Communication regarding ... .pdf
    받은서류.zip                         <- 여러 개를 체크해서 zip으로 받은 경우도 OK
```

**이력.txt 만드는 법** (둘 중 하나)
- KIPRIS 심사목록 상세화면에서 표(맨 위 출원번호부터 마지막 행까지)를 마우스로 드래그 → 복사 → 메모장에 붙여넣고 `이력.txt`(UTF-8)로 저장
- 또는 화면 캡처(`이력1.png`, `이력2.png` ...)를 폴더에 넣고 Claude Code에게 "file wrapper 정리해줘"라고 하면 캡처를 읽어 이력.txt를 만들어 줍니다
  (저장소 `.claude/skills/file-wrapper/SKILL.md` 절차)

### 실행

```bash
npm run cases -- "D:\해외사건"
```

매번 경로를 쓰기 싫으면 `config.json`에 `"casesRoot": "D:\\해외사건"`을 적어두고 `npm run cases`만 실행하면 됩니다.

### 결과

- 각 사건 폴더에 `정리\` 폴더가 생기고, 받은 파일이 `2024-03-21_EP22123456_서류명.pdf` 형식으로 복사됩니다
  (제출일이 앞에 붙어 탐색기에서 날짜순 정렬). 원본 파일은 그대로 둡니다.
- 사건루트에 `file_wrapper_이력.xlsx`
  - **사건목록**: 출원번호, 출원일, 발명의 명칭, 출원인, 이력 건수, 최근 서류
  - **이력**: 모든 이력 행 + 구분(PCT/출원 전, 출원, 중간, 등록) + 파일 링크. 파일이 있는 행(= 주요 서류)은 노란색
- 파일은 파일명(`20240321_서류명.pdf`)의 날짜·서류명으로 이력 행과 연결합니다. 연결되지 않은 파일은
  "이력에 없는 파일 - 확인 필요"로 표시되니, 파일명을 이력의 서류명과 맞춰 다시 실행하세요.
- 매 실행마다 `정리\`와 엑셀을 새로 만듭니다. 서류를 추가하거나 이력.txt를 고친 뒤 다시 실행하면 됩니다.

## 설정 바꾸기 (선택)

`config.json`을 만들면 기본값을 바꿀 수 있습니다.

```jsonc
{
  // 사무소 관리번호 정규식 (예: PN25005-KINE 형식이면 아래처럼)
  "refPattern": "\\bP[NA][A-Z]{0,2}\\d{5,6}(?:-[A-Z]{2,5})?\\b",
  // "등록"으로 분류할 서류명 단어 (소문자). 지정하면 기본 목록을 대체
  "grantKeywords": ["grant", "allowance", "certificate", "annual fee"]
}
```

## 알려진 한계

- 출원번호 자동 인식은 CN / US / EP / JP / KR 형식만 지원합니다. 그 외 국가는 mapping.csv로 지정하세요.
- KIPRIS 한국 서류명은 `거절이유 등 통지에 따른 의견의견서답변서소명서`처럼 분류명과 서류명이 붙어서 옵니다 (KIPRIS 원래 이름 그대로 둠).
- 각 PDF의 앞 2페이지만 읽습니다 (속도 때문).
- 이 저장소는 public입니다. `input/`, `output/`은 .gitignore 되어 있으니 다른 곳에 고객 자료를 두고 커밋하지 마세요.
